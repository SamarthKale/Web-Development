HTML / CSS Question Paper – Set 1
Complete Solutions with Minimal-Change Approach

How to use this guide (read this first!):
1. Every HTML page uses the same standard template. Once you copy this template, you do NOT change anything outside the body for any of these questions.
2. The parts highlighted in green are the ONLY parts you need to type / change for each question. Everything else stays the same.
3. Each question is one single .html file. Save it (e.g. Q1.html), then double-click to open in any browser (Chrome, Edge, Firefox).
4. There are no external files, no images, no linked CSS. Each file is fully self-contained and will work on its own.

The Standard HTML Template (memorize this once)

Every single answer in this paper follows this exact skeleton. The five lines below never change. You only fill in your code between <body> and </body>.

<!DOCTYPE html> <html> <head> <title>Question Title</title> </head> <body> <!-- Your answer code goes here --> </body> </html>
Tags you will reuse a lot in this paper:
• <ul> = unordered (bullet) list, <ol> = ordered (numbered) list, <li> = one list item
• <table> with <tr> (row), <th> (header cell), <td> (data cell)
• rowspan="N" makes a cell tall (covers N rows). colspan="N" makes a cell wide.
• type="I" on <ol> → I, II, III   |   type="i" → i, ii, iii   |   type="A" → A, B, C   |   type="a" → a, b, c
• list-style-type:circle → hollow circle bullets   |   square → square bullets
How to test your code: Open Notepad → paste the code → File → Save As → choose "All Files" → name it Q1.html (etc.) → double-click the saved file. It opens in your browser and shows the output.
Question 1 — Nested unordered list (Coffee / Tea / Milk)
Output: a bulleted list with Coffee, Tea, Milk where Tea has two sub-bullets (hollow circles): Black Tea and Green Tea.
<!DOCTYPE html> <html> <head> <title>Question 1</title> </head> <body> <ul> <li><b>Coffee</b></li> <li><b>Tea</b> <ul style="list-style-type:circle;"> <li><b>Black Tea</b></li> <li><b>Green Tea</b></li> </ul> </li> <li><b>Milk</b></li> </ul> </body> </html>
Trick: A list inside another <li> creates the indented sub-list. The inner <ul> uses list-style-type:circle for the hollow bullets you see in the question.
Question 2 — Table: Name / Class / School with rowspan & colspan
Header "Name" spans 2 columns. Each student row uses rowspan=2 because the Class column has 2 stacked values (number + section).
<!DOCTYPE html> <html> <head> <title>Question 2</title> </head> <body> <table border="1" cellpadding="10" cellspacing="0"> <tr> <th colspan="2">Name</th> <th>Class</th> <th>School</th> </tr> <tr> <td rowspan="2">Mahima</td> <td rowspan="2">Gupta</td> <td>11</td> <td rowspan="2">MVM School</td> </tr> <tr><td>A</td></tr> <tr> <td rowspan="2">Sri</td> <td rowspan="2">Krishn</td> <td>3</td> <td rowspan="2">LMS School</td> </tr> <tr><td>B</td></tr> <tr> <td rowspan="2">Shivika</td> <td rowspan="2">Goyal</td> <td>5</td> <td rowspan="2">SCPM School</td> </tr> <tr><td>A</td></tr> </table> </body> </html>
Trick: When a cell uses rowspan="2", the next row must NOT include that cell again — it is already taken from above. That's why the rows with just <td>A</td> have only one cell.
Question 3 — Top Frame / Left Frame / Right Frame layout
A dark-red top bar with orange text, and two orange panels (left + right) below it, all in one box.
<!DOCTYPE html> <html> <head> <title>Question 3</title> </head> <body> <div style="border:3px solid orange; width:400px;"> <div style="background:darkred; color:orange; text-align:center; padding:15px; font-weight:bold; font-size:22px; border-bottom:3px solid orange;"> Top Frame </div> <div style="display:flex;"> <div style="background:orange; color:darkred; flex:1; padding:40px; text-align:center; font-weight:bold; font-size:20px; border-right:3px solid orange;"> Left Frame </div> <div style="background:orange; color:darkred; flex:1; padding:40px; text-align:center; font-weight:bold; font-size:20px;"> Right Frame </div> </div> </div> </body> </html>
Trick: Real <frameset> needs separate files for each frame. To keep this in ONE file we draw the same layout with <div> blocks. display:flex puts the Left and Right divs side-by-side.
Question 4 — Coloured panel layout (Orange / Red / Green / Blue)
Three columns: left has Orange (top) + Blue (bottom). Middle is Red full-height. Right has Green on top with red below it.
<!DOCTYPE html> <html> <head> <title>Question 4</title> </head> <body> <div style="display:flex; width:500px; height:300px;"> <div style="display:flex; flex-direction:column; flex:2;"> <div style="background:#ff8c5a; color:white; flex:2; display:flex; align-items:center; justify-content:center; font-weight:bold; font-size:24px;">ORANGE</div> <div style="background:blue; color:white; flex:1; display:flex; align-items:center; justify-content:center; font-weight:bold; font-size:24px;">BLUE</div> </div> <div style="background:red; color:white; flex:1; display:flex; align-items:center; justify-content:center; font-weight:bold; font-size:24px;">RED</div> <div style="display:flex; flex-direction:column; flex:1;"> <div style="background:green; color:white; flex:1; display:flex; align-items:center; justify-content:center; font-weight:bold; font-size:24px;">GREEN</div> <div style="background:red; flex:2;"></div> </div> </div> </body> </html>

Question 7 — Triple-nested list (square → circle → Roman)
Outermost bullet is a square, second level is hollow circle, deepest level is Roman numerals (I, II, III).
<!DOCTYPE html> <html> <head> <title>Question 7</title> </head> <body> <ul style="list-style-type:square;"> <li><b>Maharashtra</b> <ul style="list-style-type:circle;"> <li><b>Pune</b> <ol type="I"> <li><b>Dighi</b></li> <li><b>Moshi</b></li> <li><b>Shivajinagar</b></li> </ol> </li> <li><b>Mumbai</b> <ol type="I"> <li><b>Santakruiz</b></li> <li><b>Vikroli</b></li> <li><b>Mumbra</b></li> </ol> </li> </ul> </li> </ul> </body> </html>
Trick: Each new sub-list goes INSIDE its parent <li>, before the closing </li>. Use type="I" on <ol> for capital Roman numerals.

Question 9 — HTML Form (text, file, checkboxes, submit)
A form with: text box, file picker, three checkboxes (first two pre-checked), and a Submit Query button.
<!DOCTYPE html> <html> <head> <title>Question 9</title> </head> <body> <form> <p>Enter Name of your friend <input type="text" name="friend"></p> <p>Choose the file you want to post to your friend</p> <p><input type="file" name="myfile"></p> <p>What does the file contain?</p> <p> <input type="checkbox" name="image" checked> Image <input type="checkbox" name="source" checked> Source code <input type="checkbox" name="binary"> Binary code </p> <p>You have Completed the Form. <input type="submit" value="Submit Query"></p> </form> </body> </html>

Question 13 — 3-column table with rowspan & colspan
Row 1 has 3 columns. Row 1 Cell 1 spans 2 rows. Row 3 Cell 1 spans all 3 columns.
<!DOCTYPE html> <html> <head> <title>Question 13</title> </head> <body> <table border="1" cellpadding="15" cellspacing="0" style="font-size:18px;"> <tr align="center"> <td>Columu 1</td> <td>Columu 2</td> <td>Columu 3</td> </tr> <tr align="center"> <td rowspan="2">Row 1 Cell 1</td> <td>Row 1 Cell 2</td> <td>Row 1 Cell 3</td> </tr> <tr align="center"> <td>Row 2 Cell 2</td> <td>Row 2 Cell 3</td> </tr> <tr align="center"> <td colspan="3">Row 3 Cell 1</td> </tr> </table> </body> </html>

Question 15 — Average height/weight + Red eyes table
Top-left cell is empty (rowspan=2). "Average" spans 2 columns (height + weight). "Red eyes" spans 2 rows on the right.
<!DOCTYPE html> <html> <head> <title>Question 15</title> </head> <body> <table border="1" cellpadding="10" cellspacing="0" style="background:#e8e8e8;"> <tr> <td rowspan="2"></td> <th colspan="2">Average</th> <th rowspan="2">Red<br>eyes</th> </tr> <tr> <th>height</th> <th>weight</th> </tr> <tr> <th>Males</th> <td>1.9</td><td>0.003</td><td>40%</td> </tr> <tr> <th>Females</th> <td>1.7</td><td>0.002</td><td>43%</td> </tr> </table> </body> </html>
Trick: Three special cells in row 1: empty cell (rowspan=2), "Average" (colspan=2), "Red eyes" (rowspan=2). Row 2 then ONLY needs height + weight because the other 2 are already taken from above.
Final tips for the exam:
• The green parts are everything you need to write inside <body>. The 5-line outer skeleton is identical for every answer.
• If a table looks misaligned, count the cells in each row — every row must add up to the same number of columns once you account for rowspan and colspan.
• Whenever you see "indented bullets/numbers", that means a list inside another list — write the inner list inside the parent <li> tag.
• <b> = bold. <br> = line break (used in Q15 for "Red<br>eyes").
