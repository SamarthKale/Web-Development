Practical 4: CSS Transitions & Animations

This website demonstrates various CSS animation and transition properties.

1. CSS Transition

Used: transition property (transform, background)

Hover over the box to see scaling and rotation effect.

2. Animation Timing Functions

Used: animation-timing-function (linear, ease, ease-in, ease-out)

Different speed curves affect how animation progresses.

3. Animation Delay

Used: animation-delay

The animation starts after a 2-second delay.

4. Animation Fill Mode

Used: animation-fill-mode: forwards

The element keeps its final state after animation completes.

5. Animation Play State

Used: animation-play-state

Hover over the box to pause the spinning animation.
